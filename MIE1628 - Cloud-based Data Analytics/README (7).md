# MIE1628 – Cloud Analytics

> Fall 2025 · University of Toronto · Python · Apache Spark · Jupyter Notebooks

Two projects covering distributed data processing and applied machine learning.

---

### PySpark Analytics & Movie Recommender System
**`pyspark_analytics_recommender.ipynb`** · PySpark · ALS · Collaborative Filtering

Distributed data analysis with PySpark (salary aggregation, word frequency on Shakespeare) followed by a full collaborative filtering recommender system using Alternating Least Squares. Includes EDA, RMSE/MAE/precision/recall evaluation, cross-validated hyperparameter tuning, and personalised recommendations.

---

### Heart Disease Prediction: Binary Classification
**`heart_disease_classification.ipynb`** · scikit-learn · Logistic Regression · Random Forest

Binary classifier on the UCI Cleveland Heart Disease dataset (303 patients, 13 features). Compares Logistic Regression and Random Forest using sklearn Pipelines, confusion matrices, and ROC curves. Random Forest tuned with GridSearchCV — max heart rate and chest pain type are the strongest predictors.
