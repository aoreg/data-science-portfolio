## Assignments

### Assignment 1 – Salary Analysis: Job Mode & Education Level
**Notebook:** `rego_1004909307_assignment1.ipynb` · [Open in Colab](https://colab.research.google.com/drive/1TQ0v2n05G63RHV3iw_3fQc6EHxF35aBJ)
**Report:** `rego_1004909307_assignment1.docx` · [View in Drive](https://docs.google.com/document/d/1eInHty9qlbVsYNe0FxeQQ4C2Pj4KtSVwMYElAnyOwEo)

Statistical analysis of developer salaries from the Stack Overflow Annual Developer Survey, examining the impact of:
- Job mode (remote, hybrid, in-person) on compensation
- Education level (Bachelor's, Master's, Professional) on compensation

Techniques used:
- Descriptive statistics and outlier detection (IQR method)
- Shapiro-Wilk normality test, Levene's variance test
- t-tests, ANOVA, bootstrapping

### Assignment 2 – Salary Prediction: Multi-Class Ordinal Classification
**Notebook:** `rego_1004909307_assignment2.ipynb` · [Open in Colab](https://colab.research.google.com/drive/1AOGA7hj_xYirwhcw95Gro3u0e3naL4Dc)

Full ML pipeline to predict a survey respondent's compensation bucket from Kaggle survey responses:
- Data cleaning, EDA, and preprocessing
- Feature selection using Chi-square and Lasso regression
- Model training: ordinal logistic regression
- Bias-variance analysis and hyperparameter tuning
- Evaluation with Precision, Recall, F1-score
